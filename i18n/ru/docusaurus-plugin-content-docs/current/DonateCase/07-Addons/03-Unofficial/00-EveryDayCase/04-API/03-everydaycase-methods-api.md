# Методы API

## `getNextClaimTime(String playerName)`
Возвращает время (в миллисекундах), когда игрок сможет получить следующий кейс.

**Параметры:**
- `playerName` — имя игрока.

**Возвращает:** `long` — время следующего получения.

---

## `getClaimCooldown()`
Возвращает стандартный кулдаун между открытиями кейсов.

**Возвращает:** `long` — длительность кулдауна в миллисекундах.

---

## `getCaseName()`
Возвращает название кейса, который используется в данной сессии API.

**Возвращает:** `String` — название кейса.

---

## `getKeysAmount()`
Возвращает количество ключей, доступных для открытия кейса.

**Возвращает:** `int` — количество ключей.

---

## `isPending(String playerName)`
Проверяет, есть ли у игрока невыполненное получение кейса.

**Параметры:**
- `playerName` — имя игрока.

**Возвращает:** `boolean` — `true`, если кейс ожидает получения, `false` в противном случае.
