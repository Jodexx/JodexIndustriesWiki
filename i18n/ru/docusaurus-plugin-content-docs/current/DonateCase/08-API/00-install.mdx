# Установка 

Модули DonateCase API:
- `api`
главный модуль, который содержит в себе основные конструкции для взаимодействия с DonateCase. Не имеет зависимостей.
- `spigot-api`
модуль для платформы `spigot`, содержит в себе конструкции для взаимодействия с плагином. Есть зависимость от Spigot 1.16.5.
