:::note
Для работы необходимо выбрать модуль `spigot-api` в качестве зависимости [установки](../install.mdx), чтобы использовать BukkitUtils
:::

Этот вариант предлагает использование API DonateCase с помощью других плагинов Spigot, которые содержатся в директории plugins/

<CodeBlock
        language="java"
        title="src/main/java/com/jodexindustries/testplugin/TestPlugin.java"
>
{`import org.bukkit.plugin.java.JavaPlugin;
import com.jodexindustries.donatecase.api.DCAPI;

public final class TestPlugin extends JavaPlugin {

    private final DCAPI api = DCAPI.getInstance();

    @Override
    public void onEnable() {
        this.api.getCaseKeyManager().add("case", "_Jodex__", 10); // выдаём 10 ключей от кейса "case" игроку "_Jodex__"
    }
}

`}
</CodeBlock>

<CodeBlock
        language="yaml"
        title="src/main/resources/plugin.yml"
>
{`# Зависимость от DonateCase
depend:
  - DonateCase
`}

</CodeBlock>
