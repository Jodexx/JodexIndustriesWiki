:::note
To work, you need to select the `spigot-api` module as a dependency in [installation](../install.mdx) in order to use BukkitUtils
:::

This option offers the use of the DonateCase API via other Spigot plugins, which are located in the plugins/ directory

<CodeBlock
        language="java"
        title="src/main/java/com/jodexindustries/testplugin/TestPlugin.java"
>
{`import org.bukkit.plugin.java.JavaPlugin;
import com.jodexindustries.donatecase.api.DCAPI;

public final class TestPlugin extends JavaPlugin {

    private final DCAPI api = DCAPI.getInstance();

    @Override
    public void onEnable() {
        this.api.getCaseKeyManager().add("case", "_Jodex__", 10); // give 10 keys for the "case" case to the player "_Jodex__"
    }
}

`}
</CodeBlock>

<CodeBlock
        language="yaml"
        title="src/main/resources/plugin.yml"
>
{`# Dependency on DonateCase
depend:
  - DonateCase
`}

</CodeBlock>
