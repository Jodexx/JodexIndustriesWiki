**AbstractGui** - a basic graphical interface with minimal functionality for those who are used to working with the regular **Bukkit Inventory API**

All subsequent graphical interfaces inherit from **AbstractGui**

## Example of implementing a simple menu

```java title="TestAbstractGui"
import com.jodexindustries.jguiwrapper.gui.AbstractGui;
import org.bukkit.entity.HumanEntity;
import org.bukkit.event.inventory.InventoryClickEvent;
import org.jetbrains.annotations.NotNull;

public class TestAbstractGui extends AbstractGui {
    
    public TestAbstractGui() {
        super("&cTest abstract gui"); // tip="Menu title"

        Inventory inventory = holder().getInventory(); // tip="<a href="https://github.com/Jodexx/JGuiWrapper/tree/master/api/src/main/java/com/jodexindustries/jguiwrapper/api/gui/GuiHolder.java" target="_blank">GuiHolder</a>"

        for (int i = 0; i < 5; i++) {
            ItemStack itemStack = new ItemStack(Material.DIAMOND);
            ItemMeta itemMeta = itemStack.getItemMeta();

            itemMeta.displayName(Component.text(i));
            itemStack.setItemMeta(itemMeta);

            inventory.setItem(i, itemStack);
        }
    }

    @Override
    public void onClick(@NotNull InventoryClickEvent e) {
        // reaction to the click
        HumanEntity player = e.getWhoClicked();

        player.sendMessage("You just clicked!");
    }
}
```

:::info
You can also override the methods: `onOpen`, `onClose`, `onDrag`
:::

### Opening the menu for a player

```java
TestAbstractGui gui = new TestAbstractGui();

gui.open(player); // tip="<a href="https://github.com/Jodexx/JGuiWrapper/tree/master/api/src/main/java/com/jodexindustries/jguiwrapper/api/gui/Gui.java#L45)" target="_blank">Gui#open(HumanEntity player)</a>"
```

## Constructors
**AbstractGui** makes it possible to immediately set the basic menu parameters (title, size, type, and [serializer](../serializer)) using the built-in constructors
see [JavaDocs](https://github.com/Jodexx/JGuiWrapper/tree/master/api/src/main/java/com/jodexindustries/jguiwrapper/gui/AbstractGui.java)

:::info
```java
AbstractGui(int size, String title)
AbstractGui(int size, Component title)
AbstractGui(String title)
AbstractGui(Component title)
AbstractGui(InventoryType type, Component title)
AbstractGui(InventoryType type, Component title, SerializerType defaultSerializer)
```
:::

## Updating the title
All graphical interfaces support updating the title without closing the menu using NMS

```java
@Override
public void onClick(@NotNull InventoryClickEvent e) {
    updateMenu(Component.text("New title"));
}
```

:::warning
Often when updating a menu in which there is interaction with items, it is worth updating its content, 
to do this, use the [AbstractGui#updateMenu(boolean)](https://github.com/Jodexx/JGuiWrapper/tree/master/api/src/main/java/com/jodexindustries/jguiwrapper/gui/AbstractGui.java#L266) method

The refreshData argument must be `true` to update the position of items (especially when changing the type and size). 
The menu update also needs to be done after interacting with items (in the case of reacting to [InventoryClickEvent](https://jd.papermc.io/paper/1.16.5/org/bukkit/event/inventory/InventoryClickEvent.html)), that is, after one tick:
```java
runTask(() -> { // tip="<a target="_blank" href="https://github.com/Jodexx/JGuiWrapper/tree/master/api/src/main/java/com/jodexindustries/jguiwrapper/gui/AbstractGui.java#L408">runTask</a> is a replacement for the regular<br>BukkitScheduler#runTask(Plugin, Runnable)"
    updateMenu(player, type(), size(), Component.text("New title"), true);
});
```
:::
